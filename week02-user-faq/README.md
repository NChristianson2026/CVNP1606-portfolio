\## Overview

This README provides context for the Windows 11 Text Size Issue FAQ created for Week 2. The FAQ explains a common post‑refresh problem where Windows resets accessibility settings, causing text to appear smaller than expected. The document includes verified steps, a screenshot reference, and a technician write‑up.



\---



\## Purpose of This FAQ

After a Windows 11 refresh, users may experience reduced text size across the operating system. This FAQ was created to:



\- Explain why the issue occurs  

\- Provide clear steps to restore text size  

\- Document the user’s confirmed preferred setting (150%)  

\- Reduce repeat support tickets  

\- Offer screenshot‑based guidance for clarity  



This FAQ is intended for distribution to ACME pilot group users or similar testing environments.



\---



\## Root Cause Summary

Windows 11 refresh operations often revert accessibility and display settings to default values. In this case, the Text Size setting returned to 100%, causing readability issues.



\---



\## Final Solution

The user confirmed that setting \*\*Text Size = 150%\*\* under:



\*\*Settings → Accessibility → Text size\*\*



fully resolved the issue. A screenshot was captured showing the final configuration.
