## How do I change text size in Windows 11?

**User goal:**  
Make text easier to read after a Windows 11 refresh without modifying unrelated system settings.

**Tool path tested:**  
Settings > Accessibility > Text size

**Steps:**  
1. Open **Settings**.  
2. Select **Accessibility**.  
3. Select **Text size**.  
4. Move the slider to **150%** (or preferred size).  
5. Select **Apply** and confirm the result across Windows and supported apps.

**When to escalate:**  
If text remains too small, appears blurry, or display issues continue after adjusting **Text size** and **Display > Scale**, collect device details (monitor model, resolution, GPU) and escalate for driver or hardware review.
